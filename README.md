# Provably-Secure-NLG

EIE Final Year Project 2026

## Repository Layout

- `toy_certificate/`: runnable toy row/column certificate implementation.
- `readme/toy_example_readme.md`: toy certificate usage guide.
- `readme/toy_benchmark_plots_readme.md`: benchmark CSV and plot interpretation guide.
- `readme/token_voting_readme.md`: toy and `phd_reference` token-voting setup.
- `readme/confirmed_dpa_baseline_readme.md`: confirmed DPA baseline specification.
- `readme/naive_dpa_readme.md`: implemented confirmed DPA baseline notes.
- `readme/phd_readme.md`: reference code structure and Gurobi notes.
- `scripts/run_toy_benchmark_data.sh`: runs toy benchmark data generation and writes CSV results.
- `scripts/plot_toy_benchmark.sh`: refreshes benchmark plots from an existing CSV.
- `scripts/run_toy_benchmark.sh`: convenience script for toy visualization, benchmarks, and plot refresh.
- `scripts/full_run_toy_example.sh`: full toy pipeline with tests, benchmark, and plots.
- `tests/`: lightweight toy certificate test bench.
